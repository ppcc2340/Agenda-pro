# Agenda-pro

Este repositorio contiene dos proyectos:

| Carpeta | Qué es | Estado |
|---|---|---|
| [`crm/`](crm/README.md) | **CRM interno** completo y funcional (contactos, empresas, pipeline kanban, tareas, tickets, presupuestos, workflows, informes, API). Node 22 + SQLite + React. | Listo para usar: `cd crm && npm install && npm run dev` |
| [`meri/`](meri/README.md) | Especificación de *Meri*, plataforma de productividad profesional, para construir por fases. | Especificación (sin código ejecutable) |

Arranque rápido del CRM: usuario `admin@crm.local`, contraseña `Admin1234!`, con datos de demostración cargados.
